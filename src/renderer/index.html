Structure des dossiers attendue

📁 Dossier racine
  └─ 📁 Nom_Prenom (ou Nom_Prenom_AAAA-MM-JJ)
      └─ 📁 Nom_du_setup
          ├─ 📄 fichier_u1.stl  (modèle maxillaire)
          ├─ 📄 fichier_l1.stl  (modèle mandibulaire)
          ├─ 📄 fichier_u1.pts  (ligne de découpe de fichier_u1.stl)
          └─ 📄 fichier_l1.pts  (ligne de découpe de fichier_l1.stl)
Dossiers patients
  • Nom_Prenom, par exemple Dupont_Jean
  • Nom_Prenom_AAAA-MM-JJ, par exemple Dupont_Jean_1990-05-15. La date de naissance est nécessaire si plusieurs patients portent le même nom.
  • Un patient ou un setup qui existe déjà dans InPlan est réutilisé : seuls les nouveaux fichiers sont envoyés.
Modèles (.stl)
  • Maxillaire : le nom contient « superieur », « maxil », « upper » ou se termine par _u1.stl / u1.stl
  • Mandibulaire : le nom contient « inferieur », « mand », « lower » ou se termine par _l1.stl / l1.stl
  • Le numéro indique l'étape du traitement
Lignes de découpe (.pts)
  • Un fichier .pts par modèle, avec le même nom que le .stl correspondant, par exemple Jane_U01.stl → Jane_U01.pts
  • Elles sont envoyées à la fin, après tous les modèles, une fois que le serveur a fini de les traiter : cette étape peut prendre quelques minutes.
